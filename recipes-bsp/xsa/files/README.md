# XSA Files Directory

Place your Xilinx Support Archive (XSA) file here.

## File naming
- Default expected name: `system.xsa`
- You can use any name but update the recipe's `XSA_FILE` variable

## Alternative sources
Instead of placing the file here, you can modify the recipe's SRC_URI to:
- Download from HTTP/HTTPS
- Fetch from Git repository (with LFS support)
- Use any other Yocto-supported fetcher
